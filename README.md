# Job Application Tracker

A MERN stack application for managing job applications in one place.

It helps users keep track of companies, application status, and overall
application progress through a simple dashboard.

## Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT
- bcrypt
- Recharts
- Axios

## Features

- User registration and login
- JWT-based authentication
- Create, update, and delete job applications
- Track application status
- Dashboard with application statistics
- Status-wise application breakdown
- User-specific application data
